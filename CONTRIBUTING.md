# Contributing

This list is generated. The README and everything under `data/` are written by bots from each project's README and from facts checked on GitHub. Please do not edit them by hand; a pull request that changes them will be overwritten by the next refresh.

## Add a starter

Open an [Add a starter](https://github.com/archestack/best-of-ai-starters/issues/new?template=add-app.yml) issue. A bot checks it and replies on the issue, usually within a day. What qualifies:

- open source, with a license that allows forking and commercial use (MIT, Apache-2.0, BSD, MPL; GPL/AGPL are listed with a note);
- a starter, boilerplate, template or reference app that you clone to build your own AI product, not a finished app, a library, a course or a notebook collection;
- maintained: a commit in the last 12 months, not archived;
- some adoption. Small projects can still be listed when a maintainer submits them or when the repo is a GitHub template.

Finished self-hosted AI apps belong to [Best of Self-Hosted AI](https://github.com/archestack/best-of-selfhosted-ai).

## Fix wrong or outdated data

Open a [Wrong data](https://github.com/archestack/best-of-ai-starters/issues/new?template=report-issue.yml) issue and say which field is wrong and what the correct value is, with a link to where it is documented. The entry is re-checked and rewritten from the current README.

## Opt out

Maintainers can ask for their project to be removed with the [Opt out](https://github.com/archestack/best-of-ai-starters/issues/new?template=opt-out.yml) form. Removal is applied within 24 hours and the project is not re-added by discovery.

## Content rules

Entries are written in plain language from the project's own README: what you get when you clone it, which providers and services it needs, strengths and weaknesses stated as checkable facts, and links to demo and docs when the README has them. No text is copied from other lists. Sponsorships and affiliate links, if any, are labeled and never change ordering.
